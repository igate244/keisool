# 要件（Keisool）

## コンセプト
- 個人スマホで電卓を叩く感覚で使う、計装保全の計算ツール箱
- 点検記録ではない。現場の実データ（タグ・設備名・校正記録）は入力・保存しない
- 保存するのは各ツールの入力状態・計算履歴（電卓のテープ）・お気に入り・設定のみ（端末内）

## 画面
- ホーム：ツール一覧（検索＋グループ絞り込み＋★お気に入り＋最近）
- ツール：入力すると即計算。上下どちらの欄からも逆算。値タップでコピー
- 履歴：入力が落ち着いたら自動で記録（同じツールを1分以内に続けて触った分はまとめる）。タップで条件を呼び出し
- 設定：起動時に前回のツールを開く（既定ON）、最新版に更新
- ダーク・クール・モダン。グループごとに色分け

## 第1弾（実装済み）
mA換算／温度センサー（測温抵抗体・熱電対を統合）／単位換算
（差圧レベル計は不要と判断して削除）
