# 要件（Keisool）

## コンセプト
- 個人スマホで電卓を叩く感覚で使う、計装保全の計算ツール箱＋今日のワーク・メモ
- 点検記録ではない。点検記録・タグ台帳は作らない
- 端末内に保存：各ツールの入力状態・計算履歴・お気に入り・設定・メモ（自分用）
- クラウドに保存：今日のワークのタスク（仕事仲間とリアルタイム共有）

## 今日のワーク
- 仕事仲間とチームを作ってタスクを共有。誰かがチェックするとみんなの画面にすぐ反映
- Googleログイン、招待リンクで参加
- タスクは翌日まで残る（前日からのものは「前日から」と表示）。「完了を消す」「全部クリア」で片付け
- 完了したら誰がいつ終えたかを表示

## メモ
- 自分用。端末内のみ。1行目がタイトル、★で上に固定、検索

## 画面
- ホーム：ツール一覧（検索＋グループ絞り込み＋★お気に入り＋最近）
- ツール：入力すると即計算。上下どちらの欄からも逆算。値タップでコピー
- 履歴：入力が落ち着いたら自動で記録（同じツールを1分以内に続けて触った分はまとめる）。タップで条件を呼び出し
- 設定：起動時に前回のツールを開く（既定ON）、最新版に更新
- ダーク・クール・モダン。グループごとに色分け

## 第1弾（実装済み）
mA換算／温度センサー（測温抵抗体・熱電対を統合）／単位換算
（差圧レベル計は不要と判断して削除）
