# Keisool（計装ツール）

計装保全の計算を、個人スマホで電卓感覚で使うための自分用ツール箱（PWA）。

- **mA換算**：4-20mA・1-5V・0-10V・0-20mA ⇔ % ⇔ 物理量。リニア／開平、5点・11点の点検表
- **測温抵抗体**：Pt100・Pt1000・JPt100 の温度 ⇔ 抵抗、2線式の導線抵抗の影響
- **熱電対**：K・J・T・E・N・R・S・B の温度 ⇔ 起電力、冷接点補償つき
- **単位換算**：圧力・流量・温度・長さ
- **差圧レベル計**：LRV/URV（開放タンク・密閉ドライ・ウェットレグ/ダイアフラムシール、ゼロ移調）

入力すると即計算（計算ボタンなし）。上下どちらの欄からでも逆算できる。
検索・お気に入り・最近使ったツール、計算履歴（タップで条件を呼び出し）、起動時に前回のツールを開く。
オフラインで動く。データは端末内だけ。

アプリ：https://keisool.web.app/
